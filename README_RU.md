# KomaruGram Go

Telegram Desktop клиент, написанный с нуля на языке Go. Обладает богатым функционалом и повышенным уровнем безопасности. Легко собирается и распространяется свободно на условиях минимально ограниченной лицензии.

## Почему этот проект существует?

У официального клиента Telegram Desktop и его форков есть ряд недостатков: сильная зависимость от C++ кодовой базы и библиотек ([TDLib](https://github.com/tdlib/td), Qt), затратный по времени и ресурсам компьютера процесс сборки, а также высокий порог входа для разработки собственных модификаций. Кроме того, они используют copyleft лицензию, тогда как наш репозиторий полностью свободен в плане условий распространения.

## Что внутри?

Поддерживает мультиаккаунтинг, аппаратное и программное шифрование данных, локальный (оффлайн) кэш, анимированные стикеры, наборы эмодзи, воспроизведение GIF в чате, воспроизведение/запись голосовых сообщений, просмотрщик медиа, форумы, Instant View, Markdown, Rich Messages, Mini Apps.

WIP: форматирование сообщений и инструменты отложенного постинга, администрирование чатов и каналов, истории пользователей, отправка подарков, Telegram Stars, Gram Wallet, настройки папок, кэша и уведомлений, система плагинов, хоткеи и редактируемый layout интерфейса.

За UI отвечает [Gio](https://gioui.org/) — кроссплатформенная библиотека, работающая по принципу immediate mode GUI. Выбор пал на нее, поскольку она позволяет избежать типичных ограничений фреймворков, не имеет зависимостей, не нарушает кроссплатформенную сборку, полностью совместима с Wayland и легко переносится на другие платформы.

[gotd/td](https://github.com/gotd/td) реализует MTProto и некоторые дополнительные возможности, служащие основой для любого взаимодействия с протоколом Telegram.

[wazero](https://github.com/wazero/wazero) используется в качестве высокопроизводительной WebAssembly песочницы для отрисовки стикеров. Это обеспечивает кроссплатформенность и гарантирует изоляцию кода без запуска отдельного процесса.

FFmpeg, mpv, VLC и Chromium/Firefox доступны в качестве внешних интеграций, которые необходимо предоставить самостоятельно. Однако приложение будет работать и без них, если пользователя это устраивает.

Без FFmpeg или если это выбрано в настройках, GIF и анимированные аватары воспроизводятся H.264-декодером FFmpeg, скомпилированным в WebAssembly. Он не встроен в приложение: он загружается при первой необходимости из [libavcodec-wasm](https://github.com/komarugif/libavcodec-wasm), где лежат его исходники и скрипт сборки. Свою сборку можно использовать вместо неё: см. [Переменные окружения](#переменные-окружения).

Голосовые сообщения и музыка воспроизводятся в самом приложении, без FFmpeg и внешнего плеера, прямо во время загрузки: Opus — через libopus, MP3, FLAC и WAV — через dr_libs, все скомпилированы в WebAssembly и встроены. AAC (M4A) воспроизводится декодером Fraunhofer FDK AAC, который загружается при первой необходимости из [fdk-aac-wasm](https://github.com/komarugif/fdk-aac-wasm), где лежат его исходники; про свою сборку см. [Переменные окружения](#переменные-окружения).

## С чего начать

Создайте копию этого репозитория. Убедитесь, что на вашем компьютере установлен **[Go 1.27.1](https://go.dev/dl/)** — это минимально необходимая версия. [Windows 7](./docs/BUILD_WINDOWS7.md) и [Haiku](./docs/BUILD_HAIKU.md) требуют собственные пропатченные версии Go.

В Linux могут потребоваться библиотеки разработки Wayland и X11: `vulkan-headers mesa-egl mesa-dev libxkbcommon-dev wayland-dev`. В зависимости от вашего графического окружения вы можете отключить специфичную зависимость с помощью тегов сборки: `-tags nox11` или `-tags nowayland` или `-tags novulkan`

Процесс сборки может потребовать до 4.5 ГБ оперативной памяти, учитывайте это и закрывайте ненужные приложения во время первой сборки. При нехватке оперативной памяти используйте переменные окружения `GOMAXPROCS=1 GOGC=50 GOMEMLIMIT=2GiB`. В крайнем случае можно использовать флаг `-low-memory` для ./cmd/*-build скриптов, он может вдвое понизить потребление памяти во время сборки ценой возможной потери производительности в рантайме. [Подробнее тут](./docs/BUILD_LOW_MEMORY_RU.md).

Вы можете использовать эту команду для запуска приложения на разных платформах:
```
go run ./cmd/messenger
```

Если же вам необходимо создать исполняемый файл, выберите команду под свою платформу:
### **Linux/macOS**
```
go build -ldflags="-s -w" -o komarugram ./cmd/messenger
```
### **Linux** (AppImage с иконкой)
```
go run ./cmd/appimage-build -o KomaruGram.AppImage
```
### **Windows** (поддерживается кросс-сборка)
Для вашей архитектуры:
```
go run ./cmd/windows-build -o komarugram.exe
```
Выбрать другую архитектуру:
```
go run ./cmd/windows-build -arch arm64 -o komarugram.exe
```

### **Haiku**
```
go run ./cmd/haiku-build -o ~/apps/KomaruGram
```

## Переменные окружения

Эти переменные подменяют настройку на один запуск или указывают файл, который приложение иначе скачало бы или стало искать само.

| Переменная | Что делает |
|---|---|
| `KOMARUGRAM_PROXY` | Ссылка на прокси, действует поверх списка из настроек: `tg://proxy?server=…&port=…&secret=…` (MTProto), `socks5://user:pass@host:port` или `socks5://host:port` (SOCKS5), `wss://web.telegram.org` (Telegram через WebSocket): значение флага `-proxy` по умолчанию. |
| `KOMARUGRAM_FONT`, `KOMARUGRAM_FONT_EXTRA`, `KOMARUGRAM_FONT_MONO`, `KOMARUGRAM_FONT_EMOJI` | Файл шрифта для текста, для символов, которых в нём нет, для кода и для эмодзи, поверх шрифтов из настроек. |
| `KOMARUGRAM_EMOJI_SET` | Папка набора эмодзи, которым рисовать эмодзи, поверх выбранного в настройках. |
| `KOMARUGRAM_EMOJI_PACKS` | Каталог наборов эмодзи, папка или http(s)-адрес, который настройки предложат вместо вшитого. |
| `KOMARUGRAM_MASCOT` | Папка или адрес с `index.json`, откуда берутся сцены талисмана в разделе «О программе», вместо [clawd-animations](https://github.com/komarugif/clawd-animations). |
| `KOMARUGRAM_AVCDEC` | Своя сборка H.264-декодера вместо той, что загружается из [libavcodec-wasm](https://github.com/komarugif/libavcodec-wasm): путь к файлу `avcdec.wasm` или ссылка на него. |
| `KOMARUGRAM_AACDEC` | Своя сборка AAC-декодера вместо той, что загружается из [fdk-aac-wasm](https://github.com/komarugif/fdk-aac-wasm): путь к файлу `aacdec.wasm` или ссылка на него. Без AAC-декодера не воспроизводится только звук в M4A. |
| `KOMARUGRAM_MINIAPP_BROWSER` | Браузер, в котором работают Mini Apps и, где видео играет в браузере, проигрыватель видео: программа из `PATH`, путь к ней или идентификатор flatpak-приложения. Главнее браузера, выбранного в настройках. |
| `KOMARUGRAM_TRAY_LIB`, `KOMARUGRAM_VOICE_LIB` | Только Haiku: путь к `libtrayhaiku` и к `libvoicehaiku`, которые иначе ищутся рядом с программой и в `lib` рядом с ней. |

Тесты, которым нужен настоящий аккаунт или TPM этой машины, выключены, пока их не попросят:

| Переменная | Что делает |
|---|---|
| `KOMARUGRAM_TEST_LIVE_HISTORY=1` | Проверяет историю аккаунта на этой машине, только читая её. |
| `KOMARUGRAM_TEST_MEDIA_CHANNEL` | Название чата, из которого эта проверка берёт медиа. |
| `KOMARUGRAM_TEST_LIVE_EMOJI_SETS` | Папка, в которую наборы эмодзи каталога устанавливаются из Telegram так же, как это делают настройки, только читая. |
| `KOMARUGRAM_TEST_TPM=1` | Использует TPM этой машины. |

## Переносимость

KomaruGram Go может быть портирован на множество операционных систем благодаря своей архитектуре и минимальному количеству зависимостей. Загляните в [PLATFORMS.md](./docs/PLATFORMS.md), если вам интересно изучить особенности под каждую из платформ.

| Платформа | Состояние |
|---|---|
| Windows 10/11 | ✅ Первоклассная поддержка |
| Windows 7 | ✅ Поддерживается |
| Linux (Wayland) | ✅ Первоклассная поддержка |
| Linux (X11) | ✅ Поддерживается |
| MacOS | ✅ Первоклассная поддержка |
| Haiku | ✅ Поддерживается |
| FreeBSD | ⚠️ Должен собираться, не проверено вживую |
| OpenBSD | ⚠️ В теории должен собираться, не проверено |
| NetBSD | ❓ Возможен перенос, с некоторыми оговорками |
| Android | ❓ Возможен перенос, с некоторыми оговорками |

## Лицензия

При работе с этим проектом у вас нет никаких лицензионных обязательств в отношении изменения или распространения кода. Некоторые зависимости требуют соблюдения авторских прав, но не накладывают ограничений на сам код (используются разрешительные лицензии, совместимые с MIT).

Исключений два. Оба вынесены из этого репозитория и из бинарника, загружаются во время работы, и их легко заменить или не использовать:

- H.264-декодер — из FFmpeg, по лицензии LGPL 2.1 или более поздней версии. Он лежит в [libavcodec-wasm](https://github.com/komarugif/libavcodec-wasm).
- AAC-декодер — Fraunhofer FDK AAC Codec Library, по собственной лицензии Fraunhofer: свободно копируется и распространяется вместе с исходниками, но не даёт патентных прав. AAC защищён патентами, лицензии на которые выдаёт [Via LA](https://www.via-la.com): для использования декодера, особенно коммерческого, такая лицензия может понадобиться. Поэтому Debian считает его несвободным. Он лежит в [fdk-aac-wasm](https://github.com/komarugif/fdk-aac-wasm).

Лицензии стороннего кода и файлов, которые клиент содержит или загружает, перечислены в [docs/THIRD_PARTY_LICENSES.md](docs/THIRD_PARTY_LICENSES.md) (на английском).
