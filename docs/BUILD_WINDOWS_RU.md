# Сборка исполняемого файла Windows

[English version](BUILD_WINDOWS.md).

Из корня репозитория:

```powershell
go run ./cmd/windows-build -o "$env:TEMP\KomaruGram.exe"
```

На Linux, например:

```sh
go run ./cmd/windows-build -o /tmp/KomaruGram.exe
```

Go-команда объединяет два шага из README: `go install gioui.org/cmd/gogio@latest`
и сборку через `gogio -target=windows ...`. В EXE включаются иконка приложения,
манифест и ресурс версии. Команда работает на Windows и позволяет выполнять
кросс-сборку с Linux или macOS. C-кросс-компилятор не нужен: Windows-клиент
собирается с `CGO_ENABLED=0`. Модули Go проекта не добавляются и не меняются.

`gogio` выбирается через `-gogio`, `GOGIO` или `PATH`. Если инструмент не
найден, команда устанавливает его через `go install` в каталог для платформы
сборки внутри пользовательского кеша (`komarugram-go/windows-build`), без
изменения глобального `GOBIN`. Следующие сборки используют кеш.
`-gogio-version v0.10.0` задаёт версию для установки при отсутствии инструмента;
по умолчанию используется `latest`. Чтобы переустановить свежую версию,
удалите соответствующий каталог кеша либо укажите локальный инструмент явно.

При нехватке памяти добавьте `-low-memory`:

```powershell
go run ./cmd/windows-build -low-memory -o "$env:TEMP\KomaruGram.exe"
```

Команда всегда передаёт `-p=1` через `GOFLAGS` и по умолчанию использует
`GOGC=50`. Флаг `-low-memory` также задаёт `GOMAXPROCS=1`, `GOMEMLIMIT=1792MiB`
и отключает инлайнинг только в `github.com/gotd/td/tg`. Уже заданные переменные
GC и памяти сохраняются. Это снижает расход памяти ценой скорости сборки и
возможного снижения производительности приложения; подробнее —
[в инструкции по сборке при нехватке памяти](BUILD_LOW_MEMORY_RU.md).

Флаги `-arch amd64` и `-arch arm64` выбирают архитектуру Windows.
По умолчанию используется amd64, а на машине ARM64 — arm64. Без `-o` результат
сохраняется как `KomaruGram.exe` в системном временном каталоге.
Все параметры доступны через `-h`.

Исходники копируются во временный модуль с сохранением локальных замен
зависимостей и префикса `komarugram/`, необходимого для внутренних импортов.
Существующие `.syso` исключаются, а gogio создаёт ресурсы во временном каталоге;
исходные файлы и ресурсы остаются нетронутыми. Временные файлы удаляются.
Прежний выходной EXE заменяется только после успешной сборки.
На Windows перед заменой закройте запущенную копию приложения.

Для Windows 7 нужен [go-legacy-win7](BUILD_WINDOWS7.md) (инструкция на английском)
в `PATH`: для запуска этой команды, установки gogio и компиляции клиента.
Обёртка не добавляет поддержку Windows 7 в официальный Go.

Проверено на Linux Mint 22.3, x86_64: автоустановка gogio v0.10.3,
кросс-сборки Windows amd64 и arm64 с иконкой, манифестом и ресурсом версии,
а также флаги экономии памяти. Нативный запуск обёртки на Windows/macOS
и запуск полученных EXE в этой сессии не проверялись.
